# 한국어 Store 등록 문구

## 앱 이름

AuraZip Archive Manager

## 짧은 설명

ZIP, 7Z, TAR, TGZ 파일을 만들고 열고 풀 수 있는 Windows용 압축 파일 관리자입니다.

## 자세한 설명

AuraZip Archive Manager는 Windows에서 여러 형식의 압축 파일을 다루는 데스크톱 앱입니다.

- ZIP, 7Z, TAR, TGZ 아카이브 생성 및 압축 풀기
- ZIP 및 7Z 아카이브 열기와 내부 항목 관리
- 암호화된 아카이브를 위한 암호 입력 지원
- 무결성 검사와 이미지 미리보기
- 한국어와 영어 인터페이스 및 여러 테마
- Microsoft Store를 통한 앱 업데이트

파일은 사용자가 선택한 위치에서 처리됩니다. Windows의 기본 앱 설정에서 사용자가 직접 ZIP 또는 7Z 파일을 AuraZip으로 열도록 선택할 수 있습니다.

오픈소스 구성요소 및 라이선스 고지: https://github.com/cybereun/AuraZip/blob/main/THIRD_PARTY_NOTICES.txt

## 스크린샷 캡션

리본 메뉴에서 압축 파일을 열고 내용을 확인합니다.

## 검색어

압축, ZIP, 7Z, 아카이브, 파일 압축, 압축 풀기
