## App name

AuraZip Archive Manager

## Short description

A Windows archive manager for creating, opening, and extracting ZIP, 7Z, TAR, and TGZ files.

## Description

AuraZip Archive Manager is a Windows desktop app for working with archives in several formats.

- Create and extract ZIP, 7Z, TAR, and TGZ archives
- Open ZIP and 7Z archives and manage their entries
- Enter passwords for encrypted archives
- Check archive integrity and preview images
- Korean and English interface, with multiple themes
- Updates delivered through Microsoft Store

Files are processed in locations you choose. You can select AuraZip in Windows default app settings to open ZIP or 7Z files.

Open-source components and license notices: https://github.com/cybereun/AuraZip/blob/main/THIRD_PARTY_NOTICES.txt
